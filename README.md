# Tippy Treats (рабочее название)

Мобильная one-tap игра: строим башню из живых десертов-существ. Каждое существо в башне имеет своё свойство, башня качается от неточных бросков, а между забегами игрок собирает и прокачивает коллекцию.

- **Платформы:** iOS (первый релиз), Android (следом, тот же код)
- **Стек:** TypeScript + Phaser 4 + Vite + Capacitor 8
- **Жанр:** hyper-casual / hybrid-casual, вертикальная ориентация, сессии по 1–3 минуты
- **Монетизация:** реклама за награду, покупка «Без рекламы», стартовый набор, ягоды (твёрдая валюта)
- **Статус:** идёт разработка, текущий этап смотреть в `docs/10-roadmap.md`

> Название «Tippy Treats» рабочее. Перед релизом проверить, что оно свободно в App Store, Google Play и как товарный знак (см. `docs/11-release-store.md`).

## Как начать разработку

1. Создать git-репозиторий в этой папке.
2. Открыть папку в Claude Code и дать задание: «Прочитай CLAUDE.md и docs/10-roadmap.md, выполни этап M0».
3. Дальше идти по этапам из дорожной карты по одному. После каждого этапа запускать игру в браузере (`npm run dev`) и проверять критерии готовности.

## Что в документации окончательное, а что нет

- **Правила, архитектура, список экранов и анимаций** считаются решением. Менять можно, но вместе с правкой документа.
- **Все числа баланса** (скорости, цены, награды) являются стартовыми значениями. Они подобраны на бумаге и должны уточняться после плейтестов. Все они лежат в одном месте в коде (`src/data/balance.ts`).
- **Версии библиотек и плагинов** проверять на момент установки: экосистема Capacitor быстро меняется.
