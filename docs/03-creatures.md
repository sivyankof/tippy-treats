# 03. Существа

Существа — главный отличительный элемент игры и основа коллекции. В версии 1.0 их 12. Данные лежат в `src/data/creatures.ts`.

## Общие правила

- Существо встаёт в башню на каждом 6-м слое по очереди слотов бригады (см. `02-gameplay.md`, раздел 6).
- Способность срабатывает в момент приземления, если это не промах.
- **Идеальный бросок усиливает способность в 1,5 раза.** В таблицах ниже значения для обычного броска. Что именно усиливается, указано в столбце «Усиление».
- Эффекты с длительностью «N слоёв» считают следующие слои после существа. Одинаковые эффекты не складываются, а продлеваются: остаток заменяется на новое значение, если оно больше.
- Разные множители очков перемножаются. Множители монет складываются (×2 и ×2 дают ×3).
- У каждого существа 5 уровней. Уровень усиливает способность.

## Редкость

| Редкость | Цвет рамки | Сколько в 1.0 |
|---|---|---|
| Обычное | зелёный | 4 |
| Редкое | синий | 4 |
| Эпическое | фиолетовый | 3 |
| Легендарное | золотой | 1 |

## Каталог

Столбцы уровней показывают значение способности на уровнях 1 / 2 / 3 / 4 / 5.

### Обычные

| id | Имя (ru / en) | Десерт | Способность | Ур. 1–5 | Усиление при «идеально» |
|---|---|---|---|---|---|
| `honey` | Медок / Honey | Медовик | **Липучка.** На следующих N слоях бросок с ошибкой до R пикселей засчитывается как идеальный | N = 3; R = 28 / 32 / 36 / 40 / 46 | N увеличивается |
| `puff` | Пышка / Puff | Зефир | **Раздулась.** Сразу расширяет слой на X (не шире 720) | X = 60 / 75 / 90 / 105 / 130 | X увеличивается |
| `jelly` | Желейка / Jelly | Желе | **Амортизатор.** Уменьшает качку на X пунктов | X = 40 / 50 / 60 / 75 / 100 | X увеличивается |
| `caramel` | Карамелька / Caramel | Карамельный флан | **Сладкая жила.** На следующих N слоях монеты ×2 (парящие и за комбо) | N = 5 / 6 / 7 / 8 / 10 | N увеличивается |

### Редкие

| id | Имя (ru / en) | Десерт | Способность | Ур. 1–5 | Усиление |
|---|---|---|---|---|---|
| `frosty` | Морозко / Frosty | Мороженое-сэндвич | **Заморозка.** На следующих N слоях скорость слоя ниже на P% | N = 3; P = 20 / 24 / 28 / 32 / 38 | N увеличивается |
| `brownie` | Брауни / Brownie | Брауни | **Крепыш.** Даёт щит: следующий промах не заканчивает забег, слой возвращается на перезапуск. Щит живёт N слоёв. Одновременно не больше одного щита | N = 6 / 8 / 10 / 12 / 15 | N увеличивается |
| `sprinkle` | Искорка / Sprinkle | Пончик с посыпкой | **Фейерверк.** На следующих N слоях очки ×M | N = 5; M = 2 / 2,25 / 2,5 / 2,75 / 3 | N увеличивается |
| `crumb` | Кроха / Crumb | Печенье | **Ни крошки мимо.** На следующих N слоях каждый откушенный край превращается в монеты: 1 монета за каждые K пикселей | N = 6; K = 40 / 34 / 28 / 24 / 18 | N увеличивается |

### Эпические

| id | Имя (ru / en) | Десерт | Способность | Ур. 1–5 | Усиление |
|---|---|---|---|---|---|
| `ghost` | Безешка / Meringue | Безе-привидение | **Вижу насквозь.** На следующих N слоях от краёв верхнего слоя вверх идут пунктирные направляющие, а в момент идеального совпадения летящий слой подсвечивается | N = 4 / 5 / 6 / 7 / 9 | N увеличивается |
| `twins` | Двойняшки / Twins | Макарон | **Двойная порция.** Засчитывается как 2 слоя высоты сразу (+1 к высоте) и даёт B очков | B = 50 / 80 / 120 / 170 / 250 | B увеличивается; высота остаётся +1 |
| `lemon` | Кислинка / Zesty | Лимонный тарт | **Риск.** На следующих N слоях скорость +20%, но очки ×M и каждый идеальный бросок даёт +1 монету | N = 4; M = 3 / 3,5 / 4 / 4,5 / 5 | M увеличивается |

| id | Имя (ru / en) | Десерт | Способность | Ур. 1–5 | Усиление |
|---|---|---|---|---|---|
| `rainbow` | Радужка / Rainbow | Радужный торт | **Чудо.** Следующие N бросков автоматически идеальные (кроме полного промаха), комбо растёт как обычно | N = 2 / 2 / 3 / 3 / 4 | N + 1 |

## Примеры бригад (для проверки, что выбор осмыслен)

- **Надёжная:** Медок, Желейка, Брауни. Для высоты и рекордов.
- **Жадная:** Карамелька, Кроха, Кислинка. Для фарма монет.
- **На очки:** Искорка, Кислинка, Радужка. Для заданий на очки.

Если бот-симуляция показывает, что одна бригада лучше всех остальных и по высоте, и по монетам, баланс надо править.

## Получение существ

Случайных платных наград и лутбоксов нет. Каждое существо открывается понятным способом.

| Существо | Как получить |
|---|---|
| Медок | Выдаётся в обучении |
| Пышка | Уровень пекаря 2 (бесплатно) |
| Желейка | Магазин, 300 монет |
| Карамелька | Магазин, 300 монет |
| Морозко | Магазин, 900 монет. Доступен с уровня пекаря 4 |
| Брауни | Серия дней: награда 7-го дня первого цикла |
| Искорка | Магазин, 900 монет. Доступен с уровня пекаря 6 |
| Кроха | Стартовый набор (покупка) или магазин, 1200 монет с уровня пекаря 8 |
| Безешка | Магазин, 2500 монет. Доступен с уровня пекаря 10 |
| Двойняшки | Рекорд высоты 75 в Классике (бесплатно) |
| Кислинка | Магазин, 2500 монет или 250 ягод. Доступен с уровня пекаря 12 |
| Радужка | Уровень пекаря 20 (бесплатно) или 600 ягод с уровня пекаря 5 |

Третий слот бригады открывается на уровне пекаря 3. Второй открыт сразу, но пуст до получения Пышки.

## Прокачка

Уровень поднимается за монеты. Цена не зависит от редкости в 1.0 (упрощение; пересмотреть после данных).

| Переход | Цена, монеты |
|---|---|
| 1 → 2 | 150 |
| 2 → 3 | 400 |
| 3 → 4 | 900 |
| 4 → 5 | 2000 |

Полная прокачка одного существа: 3450 монет. Всех 12: 41 400 монет. При доходе 150–250 монет в день у активного игрока это несколько месяцев целей.

## Характер и анимации существ

У каждого существа свои эмоции и одна «фирменная» анимация способности. Простые слои используют общий набор лиц. Полная спецификация в `06-art-animation-audio.md`, раздел «Существа».

| Существо | Характер | Фирменная анимация способности |
|---|---|---|
| Медок | Сонный добряк | Из-под слоя тянутся медовые нити к слою ниже |
| Пышка | Восторженная | Надувает щёки и раздувается с хлопком |
| Желейка | Невозмутимая | Дрожит волной, волна уходит вниз по башне и гасит качку |
| Карамелька | Хитрая | Подмигивает, монеты на экране начинают сиять |
| Морозко | Спокойный | Выдыхает иней, летящие слои покрываются льдинками |
| Брауни | Суровый защитник | Напрягает «мускулы», вокруг башни появляется шоколадный пузырь-щит |
| Искорка | Гиперактивная | Стреляет посыпкой как конфетти |
| Кроха | Жадина-хомяк | Открывает рот и втягивает крошки |
| Безешка | Застенчивое привидение | Становится полупрозрачной, рисует пунктир пальцем |
| Двойняшки | Спорят между собой | Половинки разъезжаются, внутри вспыхивает крем |
| Кислинка | Дерзкая | Морщится от кислоты, экран получает жёлтую виньетку |
| Радужка | Величественная | Радужная волна проходит по всему экрану |

## Формат данных

```ts
// src/data/creatures.ts
export type CreatureId =
  | 'honey' | 'puff' | 'jelly' | 'caramel'
  | 'frosty' | 'brownie' | 'sprinkle' | 'crumb'
  | 'ghost' | 'twins' | 'lemon' | 'rainbow';

export type Rarity = 'common' | 'rare' | 'epic' | 'legendary';

export interface CreatureDef {
  id: CreatureId;
  nameKey: string;          // i18n key
  descKey: string;          // i18n key, with {value} placeholders
  rarity: Rarity;
  ability: AbilityDef;      // discriminated union, see core/abilities
  unlock: UnlockDef;        // shop | bakerLevel | streak | record | iap
  palette: { body: string; glaze: string; accent: string };
}
```

Каждая способность реализуется отдельным модулем в `src/core/abilities/` с общим интерфейсом (см. `08-architecture.md`). Добавление 13-го существа не должно требовать правок в `tower-sim.ts`.
