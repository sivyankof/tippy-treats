# 12. Копилка идей

Сюда записываются идеи владельца и предложения по улучшению, которые **не входят в текущий этап**. Файл нужен, чтобы ничего не потерялось.

Правила:
- Это не задание. Claude Code не реализует ничего из этого файла, пока владелец явно не попросит.
- Новые идеи дописываются в конец таблицы «Ждут решения». Существующие строки не удаляются и не переписываются.
- Когда идея взята в работу, строка переносится в таблицу «Взято в работу» с номером этапа или коммитом.
- Когда владелец отказался от идеи, строка переносится в «Отклонено» с причиной.
