## 2. Ревью Apple: главные риски и ответы на них

### Правила 4.1 (копии) и 4.3 (спам, переполненные категории)
Игра в жанре «башня одним касанием», где клонов много. Наша защита:

1. Собственные название, иконка, персонажи, графика, звук. Никаких купленных шаблонов и чужих ассетов.
2. Отличия видны **на первых трёх скриншотах**: существа с лицами и способностями, шкала качки, экран коллекции.
3. Отличия перечислены в поле «Заметки для ревью» (текст ниже).
4. Один аккаунт, одно приложение с такой механикой. Будущие игры в том же мире должны иметь другую основную механику.

**Текст для поля App Review Notes (вставить на английском):**

> Tippy Treats is an original stacking game built from scratch (no templates or third-party game kits). All art, characters, sound and code are our own.
> What makes it different from other stacking games:
> 1. A roster of 12 collectible creatures, each with a unique ability that changes the run (magnet, shield, slow-motion, wobble damping, etc.). Players build a team of 3 before each run.
> 2. A tower wobble system: imprecise drops make the tower sway, which changes where the player must aim.
> 3. Six zones with distinct rules, plus a Daily Tower that is identical for all players each day.
> 4. A progression layer: creature upgrades, baker level, daily missions and a streak calendar.
> No account or login is required. In-app purchases can be tested in sandbox; "Restore Purchases" is in Shop and Settings. Rewarded ads are always optional.

### Правило 2.1 (завершённость)
- Никаких заглушек, «скоро», пустых экранов и тестовых надписей.
- Все кнопки работают. Все покупки отправлены на ревью вместе со сборкой.
- Приложение не падает без сети: реклама недоступна, остальное работает.

### Правило 2.3 (точность описания)
- Скриншоты сделаны из настоящей игры. Нельзя показывать то, чего нет.
- В описании не упоминать другие платформы и чужие игры.

### Правило 3.1.1 (покупки)
- Все цифровые товары продаются только через покупки в приложении.
- Кнопка «Восстановить покупки» есть.
- Платных случайных наград нет. Если они появятся в будущем, шансы надо показывать до покупки.

### Правило 5.1 (конфиденциальность)
- Ссылка на политику конфиденциальности в сторе и в настройках.
- Запрос отслеживания только через системное окно ATT; игра работает при отказе; нельзя давать награду за согласие.
- Раздел «Конфиденциальность приложения» заполнен в соответствии с SDK (см. ниже).
- Аккаунтов нет, поэтому требование об удалении аккаунта не применяется.

### Правило 1.3 и возраст
- Не выбирать категорию «Для детей»: в ней запрещена сторонняя реклама и аналитика в нашем виде.
- Возрастной рейтинг заполнить по анкете честно. Контент безобидный; наличие рекламы и покупок указать.

### Правило 4.5.4 и уведомления
- Уведомления не обязательны для игры, включаются по согласию, отключаются в настройках. Рекламы в уведомлениях нет.

## 3. Раздел «Конфиденциальность приложения» (ориентир)

Заполнять по актуальной документации каждого SDK. Ожидаемая картина:

| Тип данных | Кто собирает | Цель | Привязка к личности | Отслеживание |
|---|---|---|---|---|
| Идентификатор устройства (рекламный) | AdMob | Сторонняя реклама | Нет | Да (при согласии ATT) |
| Примерное местоположение | AdMob | Сторонняя реклама | Нет | Да |
| Данные об использовании (взаимодействие с продуктом, рекламные данные) | AdMob, Firebase | Реклама, аналитика | Нет | Частично |
| Диагностика (сбои, производительность) | Firebase Crashlytics | Работа приложения | Нет | Нет |
| История покупок | RevenueCat | Работа приложения | Нет | Нет |

То же самое отражается в разделе «Безопасность данных» Google Play.

## 4. Чек-лист перед отправкой на ревью iOS

**Сборка**
- [ ] Боевые идентификаторы рекламы и ключи подставлены из `.env`, тестовые режимы выключены.
- [ ] Инструменты отладки недоступны в релизной сборке.
- [ ] Номер версии и номер сборки увеличены.
- [ ] Иконки всех размеров, заставка, название под иконкой не обрезается.
- [ ] `Info.plist`: текст для ATT, запрет поворота, `ITSAppUsesNonExemptEncryption = false`.
- [ ] Манифест конфиденциальности присутствует.

**Поведение**
- [ ] Чистая установка: обучение → первый забег → дом, без запросов разрешений до конца первого забега.
- [ ] Режим полёта: игра работает, кнопки рекламы неактивны, покупки показывают понятную ошибку.
- [ ] Отказ от ATT, отказ от уведомлений: игра работает.
- [ ] Сворачивание во время забега, рекламы и покупки не ломает состояние.
- [ ] Входящий звонок и музыка из другого приложения: звук игры ведёт себя корректно.
- [ ] Самый маленький поддерживаемый iPhone и самый большой: интерфейс не обрезан.
- [ ] iPad: либо приложение помечено «только iPhone» и нормально выглядит в режиме совместимости, либо интерфейс адаптирован. Для 1.0 достаточно первого.
- [ ] Русский и английский интерфейс проверены целиком.
- [ ] «Восстановить покупки» работает на устройстве без сохранения.
- [ ] 30 минут игры без падений и утечек памяти.

**Страница в сторе**
- [ ] Название (до 30 символов), подзаголовок (до 30), ключевые слова (до 100).
- [ ] Описание en и ru.
- [ ] Скриншоты 6,9" и 6,5" (и 5,5", если требуется на момент отправки).
- [ ] Видео-превью 15–30 секунд (желательно).
- [ ] Возрастной рейтинг, категория «Игры → Казуальные» (вторая: «Головоломки» или «Аркады»).
- [ ] Ссылки: поддержка, политика конфиденциальности.
- [ ] Заметки для ревью (текст из раздела 2).
- [ ] Покупки приложены к версии, у каждой есть скриншот для ревью.

## 5. Страница в сторе

### Скриншоты (порядок важен)
1. Башня с существами и крупной надписью о главной идее: «Собери бригаду. Построй башню».
2. Момент срабатывания способности с эффектом: «У каждого вкусняша своя суперсила».
3. Качающаяся башня и шкала качки: «Башня качается. Удержи её!».
4. Экран коллекции: «Открой и прокачай всех 12».
5. Башня дня: «Одна башня в день для всего мира».
6. Космическая зона на большой высоте: «Как высоко заберёшься ты?».

### Ключевые слова (отправная точка, уточнить в инструменте ASO)
`stack, tower, tap, cake, dessert, cute, creatures, collect, casual, one tap, offline, relax, timing`
Не использовать названия чужих игр и брендов.

### Описание, первая строка
«Tap to stack living desserts into a wobbly tower. Each creature has a power. How high can you go?»

## 6. TestFlight

- Внутреннее тестирование: сразу после M7.
- Внешнее тестирование (до 10 000 человек по ссылке) требует короткого ревью бета-версии. Запускать после M8, собрать отзывы 5–10 человек, не видевших игру.
- Что спросить у тестировщиков: что было непонятно в первые 2 минуты; на какой высоте стало скучно или слишком сложно; какое существо любимое; раздражала ли реклама.

## 7. Google Play (после iOS)

- Для новых личных аккаунтов разработчика Google требует закрытое тестирование с группой тестировщиков в течение нескольких дней подряд, прежде чем откроет публикацию. Точные числа проверить в Play Console: они менялись. Заложить на это 2–3 недели и заранее найти тестировщиков.
- Целевой уровень API должен соответствовать текущему требованию Google Play.
- Анкеты: рейтинг контента, целевая аудитория (13+), безопасность данных, декларация о рекламе.
- Проверить на устройствах: аппаратная кнопка «Назад», разные пропорции экрана, слабое устройство (режим «Меньше эффектов»).
- Формат сборки: Android App Bundle.
