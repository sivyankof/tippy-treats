# 07. Экраны и интерфейс

Ориентация только вертикальная. Все экраны учитывают безопасные зоны (вырез, индикатор «домой»). Управление одной рукой: важные кнопки в нижних двух третях экрана.

## Карта экранов

```
Boot → Preload → [первый запуск] → Game (обучение) → Results → Home
                 [не первый]     → Home

Home ──► Game ──► Continue? ──► Results ──► Home / Game
  │
  ├─► Team (бригада)
  ├─► Collection ──► CreatureDetail
  ├─► Shop
  ├─► Daily (башня дня) ──► Game
  ├─► Missions (окно)
  ├─► Streak calendar (окно)
  └─► Settings (окно)
```

Нижняя панель навигации на Home: **Магазин · Коллекция · Играть · Башня дня · Задания**. «Играть» в центре, крупнее остальных.

## 1. Boot / Preload

- Boot: загрузка шрифта и логотипа, чтение сохранения, миграции.
- Preload: полоса загрузки в виде растущей башенки из 5 слоёв. Целевое время до главного экрана: ≤ 2,5 секунды на iPhone 11.

## 2. Home (главный экран)

```
│                              │

│                              │
│       ┌──────────────┐       │
│       │  (•ᴗ•) (•ᴗ•) (•ᴗ•) │  полка с бригадой, живые

│   [ Стартовый набор $1.99 ]  │  только первые 7 дней
│                              │

```

- Касание полки открывает экран бригады.
- Значки на нижней панели показывают красную точку, если есть что забрать (выполненное задание, непройденная башня дня, доступная покупка за монеты).
- Фон: кухня с лёгким параллаксом от наклона устройства (если доступен гироскоп; иначе медленное автоматическое покачивание).

## 3. Team (бригада)

- Вверху 3 слота. Внизу сетка открытых существ.
- Касание существа в сетке ставит его в первый свободный слот; касание слота убирает. Перетаскивание тоже работает.
- Под слотами строка с порядком появления: «6-й слой → 12-й → 18-й».
- Долгое нажатие на существо открывает его карточку.
- Бригада не обязательна: забег можно начать и с пустыми слотами. Если есть свободный слот и незанятые существа, у кнопки «Играть» показывается подсказка.

## 4. Game (забег)

```
┌──────────────────────────────┐
│ ⏸                    🪙 12   │
│            42                │  высота, крупно
│          3 250               │  очки, мельче
│     качка [▓▓▓░░░░░░░]       │
│  [❄ 2] [✨ 4]     [🍯] через 2 слоя │  эффекты слева, следующее существо справа
│                              │
│      ◄══ летящий слой ══►    │
│                              │
│         ▓▓▓▓▓▓▓▓▓            │
│        ▓▓▓▓▓▓▓▓▓▓▓           │  башня
│        ▓▓▓▓▓▓▓▓▓▓▓▓          │
└──────────────────────────────┘
```

- Касание в любом месте, кроме кнопки паузы, роняет слой.
- Пауза: окно с кнопками «Продолжить», «Заново», «Домой», переключатели звука. При выходе из паузы отсчёт «3-2-1».
- При сворачивании приложения автоматически включается пауза.
- Интерфейс минимален и полупрозрачен, чтобы не мешать башне.

## 5. Continue? (окно продолжения)

- Заголовок «Ещё попытка?», высота башни, круговой таймер 5 секунд.
- Кнопка «Смотреть рекламу» (или «15 🍓» / «30 🍓» для второго продолжения).
- Кнопка «Нет, спасибо» появляется через 1 секунду (защита от случайного нажатия), мелкая.
- Если реклама недоступна и ягод не хватает, окно не показывается.

## 6. Results (результаты)

Элементы появляются каскадом сверху вниз:

1. Высота (крупно) и метка «Новый рекорд!», если он побит.
2. Очки, лучшее комбо, число активированных способностей.
3. Заработанные монеты с разбивкой (парящие, комбо, бонус высоты). Кнопка «×2 за рекламу».
4. Полоса опыта пекаря с анимацией заполнения. При новом уровне показ награды.
5. Прогресс заданий, изменившийся за забег.
6. Строка «почти получилось» (см. `04-meta-retention.md`, раздел 6).
7. Кнопки: **«Ещё раз»** (крупная), «Домой», «Поделиться».

«Поделиться» создаёт картинку: башня целиком в уменьшенном виде, высота, название игры. Используется системное окно «Поделиться».

## 7. Collection (коллекция)

- Сетка 3×4 карточек. Открытые: живое существо, имя, уровень звёздочками, рамка цвета редкости. Закрытые: силуэт и способ получения («300 🪙», «Ур. пекаря 10», «Рекорд 75», «7-й день серии»).
- Вверху счётчик «7 / 12».
- Касание открывает CreatureDetail.

## 8. CreatureDetail (карточка существа)

- Крупное живое существо, реагирует на касание.
- Имя, редкость, описание характера одной строкой.
- Способность: текст со значениями текущего уровня; значения следующего уровня показаны зелёным («3 слоя → **4 слоя**»).
- Кнопка «Улучшить за 400 🪙» или «Купить за 900 🪙». Если монет не хватает, кнопка серая и показывает, сколько не хватает.
- Кнопка «Попробовать»: короткая демонстрация способности на башне из 8 слоёв без наград. Доступна и для закрытых существ.
- Кнопка «В бригаду».

## 9. Shop (магазин)

Разделы сверху вниз:
1. **Стартовый набор** (если доступен), с настоящим таймером.
2. **Существа за монеты**, доступные по уровню пекаря.
3. **Бесплатно:** 25 монет за рекламу (3 раза в день).
4. **Ягоды:** 4 пакета, на среднем пометка «Популярный», на большом «Выгодно».
5. **Обмен ягод на монеты.**
6. **Без рекламы.**
7. Внизу мелко: «Восстановить покупки», ссылки на условия и политику конфиденциальности.

## 10. Daily (башня дня)

- Заголовок с датой и таймером до смены.
- Бригада дня: три карточки существ.
- Особенности дня: значки правил зон, которые встретятся.
- Полоса наград с отметками 15 / 30 / 50 / 75 / 100 и лучшим результатом.
- Попытки: три значка; использованные серые. Кнопка «+1 за рекламу».
- Кнопка «Играть».
- Если уровень пекаря < 5: экран показан с замком и текстом «Откроется на 5 уровне».

## 11. Missions (окно заданий)

- Три карточки: описание, полоса прогресса, награда, кнопка «Забрать» по выполнении.
- Кнопка замены задания (1 раз в день).
- Внизу сундук дня с полосой 0/3.
- Таймер до новых заданий.

## 12. Streak calendar (окно серии)

- 7 ячеек наград, текущий день подсвечен и пульсирует, прошедшие отмечены галочкой.
- Кнопка «Забрать». После нажатия награда вылетает в счётчики.
- Показывается автоматически при первом входе за день (после загрузки главного экрана).

## 13. Settings (окно настроек)

- Музыка, звуки, вибрация (переключатели).
- Меньше эффектов (переключатель).
- Язык (English / Русский; по умолчанию язык системы).
- Уведомления: общий переключатель и по типам.
- Восстановить покупки.
- Настройки конфиденциальности (повторное открытие формы согласия на рекламу, где применимо).
- Политика конфиденциальности, условия использования, поддержка (почта).
- Версия приложения и идентификатор установки (мелко, для обращений в поддержку).
- Сбросить прогресс (с двойным подтверждением).

## Общие правила интерфейса

- Минимальный размер области касания: 88×88 условных пикселей (44 точки).
- Весь текст через i18n. Русские строки в среднем на 20–30% длиннее английских: все кнопки и плашки должны выдерживать это без переноса, при необходимости текст автоматически уменьшается до 80%.
- Числа форматируются по локали: `1 250` для ru, `1,250` для en. Большие числа сокращаются: `12,5 тыс.` / `12.5K`.
- Аппаратная кнопка «Назад» на Android: закрывает окно, с экрана возвращает на Home, на Home спрашивает о выходе, в забеге ставит паузу.
- Цвет не является единственным носителем информации: редкость дублируется подписью, состояние качки дублируется пульсацией.
