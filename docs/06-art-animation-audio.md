# 06. Графика, анимация, звук

Требование владельца: игра должна быть **живой и анимированной**. Этот документ является спецификацией «сочности». Любой элемент, который в игре стоит неподвижно дольше 2 секунд, считается недоделкой.

Все длительности и амплитуды лежат в `src/data/anim.ts`, а не в коде сцен.

## 1. Визуальный стиль

- **Глянцевый мультяшный 2D с ощущением объёма.** Ориентир по ощущению: леденцовый блеск, сочные цвета, толстые мягкие формы. Копировать чужие элементы нельзя, ориентир только по настроению.
- Объём создаётся приёмами 2D: градиент сверху вниз, блик в верхней трети, тёмная кайма снизу, мягкая тень под объектом.
- Контур: тёмный оттенок основного цвета, толщина 6. Чёрных контуров нет.
- Скругления везде. Острых углов нет.
- Вид строго сбоку. Перспективы нет, глубина передаётся параллаксом фона.

### Палитра

| Назначение | Цвет |
|---|---|
| Основной акцент (кнопка «Играть») | `#FF5C8A` |
| Вторичный акцент | `#7C5CFF` |
| Монеты, золото | `#FFC93C` |
| Ягоды | `#E8334A` |

### Шрифт

**Nunito** (лицензия OFL, есть кириллица), начертания ExtraBold и Black. Файлы шрифта лежат в репозитории. Числа очков и высоты рисуются с обводкой 8 и тенью.

## 2. Как делается графика без художника

В версии 1.0 вся графика создаётся в репозитории, без внешних картинок.

1. **Слои башни рисуются кодом** (Phaser Graphics), потому что их ширина меняется при откусывании: скруглённый прямоугольник коржа, сверху глазурь с потёками, блик, нижняя тень. Перерисовка происходит только при изменении ширины, то есть один раз за бросок.
2. **Лица, иконки, монеты, элементы интерфейса** — SVG-файлы в `assets/svg/`, написанные вручную. Загружаются через загрузчик SVG Phaser с нужным масштабом.
3. **Фоны** собираются из простых SVG-фигур в несколько слоёв параллакса.
4. **Частицы** используют 5–6 маленьких текстур: круг, звезда, крошка, капля, искра, конфетти.

Ключи текстур стабильны (`face_eye_open`, `icon_coin`…). Позже графику можно заменить работой художника без правок кода.

## 3. Анатомия слоя

Слой — контейнер из частей, чтобы каждую можно было анимировать отдельно:

```
LayerView (container)
├── shadow        мягкая тень на слое ниже
├── body          корж: Graphics, ширина = текущая ширина слоя
├── glaze         глазурь с потёками, обрезана по ширине body
├── gloss         блик, полупрозрачный белый овал
├── face (container), центрируется по оставшейся ширине
│   ├── eyeL, eyeR   белок + зрачок + блик, зрачки двигаются отдельно
│   ├── browL, browR только у существ
│   ├── mouth        набор форм: smile, open, o, flat, scared, yum
│   └── cheeks       румянец
└── extras        уникальные детали существа (посыпка, ушки-привидения, льдинки)
```

Если ширина слоя меньше 200, лицо уменьшается пропорционально; меньше 90 — остаются только глаза.

## 4. Анимации забега

Обозначения плавности: `backOut` (с перелётом), `elasticOut` (пружина), `quadIn/Out`, `sineInOut`.

### Летящий слой
| Что | Описание | Параметры |
|---|---|---|
| Появление | Влетает из-за края, растянут по горизонтали | scaleX 1,15 → 1 за 180 мс, `backOut` |
| Полёт | Лёгкое покачивание вверх-вниз | ±6 пикселей, период 0,8 с |
| Взгляд | Зрачки смотрят вниз, на верхушку башни | смещение зрачка до 5 пикселей в сторону цели |
| Волнение | Чем ближе к центру цели, тем шире улыбка; у края рот «o» | переключение формы рта |
| Тень-подсказка | На верхнем слое башни видна тень летящего слоя | прозрачность 0,18 |

### Падение и приземление
| Что | Описание | Параметры |
|---|---|---|
| Падение | Слой вытягивается по вертикали, глаза зажмурены | scaleY 1,12, scaleX 0,92; 110 мс `quadIn` |
| Удар | Сплющивание и возврат | scaleY 0,72 / scaleX 1,14 → 1 / 1 за 320 мс `elasticOut` |
| Волна по башне | Каждый слой ниже сплющивается слабее и с задержкой | 8 слоёв вниз, задержка 28 мс на слой, сила ×0,7 на слой |
| Пыль | Облачка крошек из-под краёв слоя | 6–8 частиц с каждой стороны, жизнь 350 мс |
| Тряска камеры | Короткий толчок вниз | 6 пикселей, 90 мс; при «идеально» нет тряски, только подскок +4 |
| Лицо | После удара моргает и улыбается | моргание 120 мс, затем `smile` |

### Откусывание края
| Что | Описание | Параметры |
|---|---|---|
| Срез | Откушенная часть отделяется как отдельный кусок с тем же цветом | вращение ±40°/с, падение с ускорением 2400, жизнь 900 мс |
| Крошки | Вдоль линии среза | 10–14 частиц «крошка» цвета коржа |
| Капля глазури | С края среза стекает капля | 1–2 капли, 500 мс |
| Реакция | Лицо слоя на 400 мс делает «ой»: брови домиком, рот `o` | — |
| Линия среза | На срезе виден «бисквит» более светлого тона с пористой текстурой | постоянная деталь |

### Идеальный бросок
| Что | Описание | Параметры |
|---|---|---|
| Кольцо | От слоя расходится светящееся кольцо | масштаб 0,6 → 1,6, прозрачность 0,9 → 0 за 380 мс |
| Блик | По слою пробегает белая полоса-блик слева направо | 260 мс |
| Искры | Звёздочки из краёв | 12 частиц, цвет `#3DDC97` и белый |
| Текст | Всплывает «Идеально!», при комбо «×3», «×4»… | появление `backOut` 160 мс, подъём на 80 пикселей, исчезновение 500 мс; размер растёт с комбо до ×1,6 |
| Башня | Все видимые лица на 300 мс радуются | рот `smile`, глаза дугой |
| Расширение (комбо ≥ 4) | Слой раздувается с хлопком, края пружинят | 240 мс `elasticOut` |
| Комбо ≥ 8 | Фон на мгновение светлеет, вокруг башни постоянный мягкий ореол до сброса комбо | — |

### Качка
| Что | Описание |
|---|---|
| Наклон | Слои смещаются по синусоиде (формулы в `02-gameplay.md`) и слегка поворачиваются: до 3° у верхушки |
| Лица | При качке > 40 глаза слоёв «плывут» с запаздыванием, рты становятся `flat`; при > 70 — `scared`, капельки пота |
| Шкала | Заполняется волной; выше 70 пульсирует и краснеет |
| «Чих» (качка 100) | Башня замирает на 150 мс, верхний слой сжимается, с обеих сторон вылетают крошки, все лица зажмуриваются; звук чиха |

### Монеты, золотой слой
| Что | Описание |
|---|---|
| Парящая монета | Вращается (сжатие по X), подпрыгивает ±8, искрится каждые 1,2 с |
| Сбор | Монета подпрыгивает, летит по дуге в счётчик монет за 450 мс; счётчик подпрыгивает; число прокручивается |
| Золотой слой | Переливается бегущим бликом, вокруг искры; в полёте оставляет золотой шлейф |
| Ягода | При получении вылетает крупно в центр экрана, затем летит в счётчик |

### Смена зоны
- Плашка с названием зоны выезжает сверху (`backOut`, 300 мс), висит 1,2 с, уезжает.
- Фон плавно перетекает в новый за 1,5 с: градиент неба и слои параллакса.
- Забег не останавливается.

### Промах и конец забега
| Этап | Описание | Длительность |
|---|---|---|
| Замедление | Время замедляется до 0,3; слой падает мимо, вращаясь; лицо в ужасе | 400 мс |
| Реакция башни | Все лица смотрят вслед упавшему слою | 300 мс |
| Окно «Продолжить?» | Выезжает снизу, круговой таймер 5 с | — |
| Отказ | Башня рассыпается сверху вниз: слои разлетаются с небольшим случайным импульсом, подпрыгивают, лица улыбаются (не трагедия, а веселье); камера быстро проезжает вниз вдоль всей башни | 1,2–1,8 с в зависимости от высоты |
| Новый рекорд | Конфетти на весь экран, лента «Новый рекорд!», фанфары | 1,5 с |

### Способности существ
Общий шаблон: слой-существо при приземлении вспыхивает цветом редкости, проигрывает фирменную анимацию (см. `03-creatures.md`), сверху появляется значок эффекта со счётчиком оставшихся слоёв. Пока эффект активен, значок слегка пульсирует, за 1 слой до конца мигает.

Усиленная способность (после идеального броска) дополнительно даёт второе кольцо цвета редкости и надпись «Усилено!».

## 5. Фоны и камера

- Камера следует за верхушкой башни с запаздыванием: приближение к цели на 12% расстояния за кадр (сглаживание). На экране видно 9–11 верхних слоёв.
- Фон состоит из 4 слоёв параллакса с коэффициентами прокрутки 0,05 / 0,15 / 0,3 / 0,6.
- Небо меняет градиент по высоте: тёплая кухня → дневное небо → закат → ночь → космос.
- Фоновая жизнь в каждой зоне, минимум 3 движущихся элемента:

| Зона | Элементы |
|---|---|
| Кухня | Пар из кастрюли, качающиеся половники, часы с ходящим маятником, пролетающая муха |
| Витрина | Мигающие гирлянды, прохожие-силуэты за стеклом, вращающийся торт |
| Крыша | Птицы, дым из труб, развевающееся бельё |
| Облака | Плывущие облака в 3 слоя, воздушный шар, самолётик |
| Звёзды | Мерцающие звёзды, падающая звезда раз в 6–10 с, луна с лицом |
| Космос | Планеты, спутник, комета, туманность с медленным переливом |

## 6. Анимации интерфейса

| Элемент | Поведение |
|---|---|
| Любая кнопка | Нажатие: масштаб 0,92 за 60 мс; отпускание: 1,06 → 1 `backOut` 180 мс; звук клика; лёгкая вибрация |
| Кнопка «Играть» | Постоянно «дышит»: масштаб 1 ↔ 1,04, период 1,6 с; по ней раз в 3 с пробегает блик |
| Переходы между экранами | Содержимое уезжает вниз и затемняется (200 мс), новое выезжает сверху с `backOut` (280 мс). Элементы нового экрана появляются каскадом с шагом 40 мс |
| Всплывающие окна | Затемнение фона 150 мс; окно: масштаб 0,7 → 1 `backOut` 240 мс |
| Числа | Любое изменение числа (монеты, опыт, очки) прокручивается за 400–800 мс |
| Получение награды | Предметы вылетают веером из центра и летят в свои счётчики |
| Полоса опыта | Заполняется плавно; при уровне вспышка, полоса обнуляется и продолжает заполняться |
| Новое существо | Отдельная сцена: коробка трясётся, открывается, существо выпрыгивает, лучи вращаются за ним, имя и редкость появляются по буквам |
| Карточки коллекции | Существа в карточках моргают и дышат; заблокированные показаны тёмным силуэтом, который слегка покачивается |
| Главный экран | Существа бригады на полке: моргание раз в 2–5 с (случайно), зевок, взгляд друг на друга, реакция на касание (подпрыгивание и писк) |
| Счётчик серии | Огонёк постоянно колышется; при росте серии вспыхивает |

## 7. Звук

Звуковые эффекты синтезируются кодом через Web Audio (`src/services/audio/synth.ts`), файлы не нужны.

| Событие | Звук |
|---|---|
| Обычный бросок | Мягкий «шлёп» с низким тоном; высота тона слегка случайна (±5%) |
| Идеальный бросок | Чистая нота колокольчика. Ноты идут по мажорной пентатонике вверх с каждым шагом комбо (до-ре-ми-соль-ля и на октаву выше), максимум 12 ступеней |
| Откусывание | Хруст (короткий шум с фильтром) |
| Монета | Двойной высокий «дзынь» |
| Ягода | Аккорд из трёх нот |
| Способность | Свой короткий звук на каждую редкость + общий «пуф» |
| Чих | Комичный писк вниз |
| Промах | Нисходящий свист и «бум» |
| Рассыпание башни | Серия шлепков с убывающей громкостью |
| Рекорд | Фанфары из 5 нот |
| Кнопки | Короткий клик |
| Существо на главном экране | Писк, у каждого существа своя высота тона |

**Музыка.** Лёгкий зацикленный трек. В 1.0 два варианта на выбор владельца: (а) простая генеративная мелодия из синтезатора, (б) готовый трек с лицензией CC0 или купленной лицензией. Громкость музыки приглушается на 40% во время окон. С каждой зоной добавляется инструментальный слой, если выбран вариант (а).

Настройки: отдельные выключатели музыки, звуков и вибрации. Звук уважает беззвучный режим устройства. При сворачивании приложения звук ставится на паузу.

## 8. Вибрация (Capacitor Haptics)

| Событие | Тип |
|---|---|
| Обычный бросок | Лёгкий удар (light) |
| Идеальный бросок | Средний удар (medium) |
| Откусывание большого края (> 30% ширины) | Тяжёлый удар (heavy) |
| Способность | Уведомление «успех» |
| Чих, промах | Уведомление «ошибка» |
| Кнопки | Выбор (selection) |
| Рекорд | Серия из трёх средних ударов |

## 9. Производительность

- Цель: стабильные 60 кадров в секунду на iPhone 11 и на Android среднего уровня 2021 года.
- Слои ниже видимой области превращаются в «спящие»: анимации лиц отключены, объекты возвращаются в пул. Одновременно живых слоёв не больше 16.
- Частицы: общий лимит 250 одновременно. При падении частоты кадров ниже 50 в течение 2 секунд автоматически включается режим «меньше эффектов» (частиц вдвое меньше, без волны сплющивания).
- В настройках есть переключатель «Меньше эффектов» и он же включается, если в системе включено «Уменьшение движения».

## 10. Проверка «сочности» (критерии приёмки)

Перед закрытием этапа M3 (см. дорожную карту) пройти по списку:

- [ ] На экране забега нет ни одного объекта, неподвижного дольше 2 секунд.
- [ ] Каждый бросок даёт одновременно анимацию, звук и вибрацию.
- [ ] Идеальный бросок легко отличить от обычного с выключенным звуком.
- [ ] Идеальный бросок легко отличить от обычного с закрытыми глазами (по звуку и вибрации).
- [ ] Комбо из 6 идеальных ощущается заметно «громче» одиночного.
- [ ] Конец забега выглядит забавно, а не обидно.
- [ ] Все числа в интерфейсе меняются прокруткой, а не скачком.
- [ ] 60 кадров в секунду при башне в 100 слоёв.
