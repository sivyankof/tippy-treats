# Сайт Tippy Treats (исходник)

Внутренние заметки; этот файл в публичный репозиторий не публикуется. Статический сайт игры: политика конфиденциальности, условия использования и поддержка на английском и русском, для ссылок в App Store Connect, Google Play и в настройках игры. Без сборки, внешних шрифтов, библиотек и счётчиков; язык переключает `lang.js` (`?lang=en` / `?lang=ru`, иначе язык браузера, иначе английский).

Тексты политики соответствуют версии 1.0 игры (`docs/09-services-analytics.md`, разделы 4–8 и 10; `docs/11-release-store.md`, раздел 3). Если состав SDK, рекламы или данных меняется, сначала правится документ, затем политика на обоих языках, затем публикация с новой датой (`--effective-date`).

## Хостинг и публикация

GitHub Pages репозитория `sivyankof/tippy-treats-site`, адрес https://sivyankof.github.io/tippy-treats-site/. Адреса страниц и почта поддержки лежат в одном месте: `src/data/app/site.ts`. Порядок публикации и страж личных данных — `docs/11-release-store.md`, раздел 9. Команда: `node scripts/site/publish-site.cjs` (проверка без отправки: `--dry-run`).

## Что подставляется при публикации

| В исходнике | Чем заменяется |
|---|---|
| `[SUPPORT_EMAIL]` | `SITE.supportEmail` (пока `null`: публикация отказывает) |
| `<time data-effective></time>` | дата начала действия (первая публикация — дата этого дня) |

Других заглушек в страницах нет (это проверяет тест `scripts/site/site-guard.test.ts`).

## Как посмотреть локально

Открыть `site/index.html` в браузере, язык: `index.html?lang=ru`. Страница `404.html` ссылается от корня хоста с префиксом `/tippy-treats-site/` (так её отдают Pages для любого неизвестного адреса), поэтому в просмотре по файлу она без оформления.
